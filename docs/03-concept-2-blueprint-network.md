# 03 · Concept 2 — *SHEET 02/03* (architectural blueprint / crypto network)

> **One-sentence idea:** The arena as an architect's elevation sheet — two tiers
> of arcade bays, dimension lines and a validator mesh drawn over it — printed
> like a technical drawing on a bone-coloured tee.

*Master file:* `design/concepts/concept-2-blueprint-network.svg` (300 × 380 mm)
*Mockup:* `mockups/concept-2-mockup-back.png`

## Visual story

A single drawing sheet is placed on the back of the shirt: a double-ruled
border, a sheet number (`SHEET 02/03`), a plan view of the arena in the top-left
corner, and a full elevation of the two-tier arcade across the middle with
dimension lines, a dash-dot centreline and ground hatching. Laid over the
elevation is a **node graph** — the Solana validator mesh — with two red nodes
marking the critical path (the same red used for the dimension lines). Bottom
left: the SuperteamTR monogram with the wordmark, the headline `BUILD THE ARENA`
and the official Solana logotype. Bottom right: a title block with project,
drawing, scale, ecosystem and print data — the "official merchandise" tell.

## Recommended T-shirt colour

Bone / natural off-white (`#E9E4D8`) — a blueprint reads best on paper. Also
deliverable reversed on washed black.

## Main graphic structure

| Layer | Element |
|---|---|
| Sheet | double border rule, header row (`SUPERTEAMTR // ARENA SECTION`, `SHEET 02/03`) |
| Plan | 24-bay circular plan with cross axes and one red core dot |
| Elevation | upper tier 11 bays, lower tier 13 bays, attic band, cornice ticks, ground line + hatching |
| Dimensions | red dimension line with end ticks and the note `Ø 268 mm / 11 BAYS × 2 TIERS` |
| Network | 11-node validator cluster, 16 links, two red nodes/edges, `LATENCY 400 MS / 2 TIERS` |
| Brand block | official monogram + `SuperteamTR` wordmark, headline, official Solana logotype |
| Title block | 5 rows: project, drawing, scale, ecosystem, print |

## Typography direction

* **Anton** for `BUILD THE ARENA` (the only "loud" line).
* **Space Grotesk 700** for the `SuperteamTR` wordmark lockup.
* **JetBrains Mono** for every technical label, dimension note and title-block
  row — this is what makes the sheet believable: same voice as real drawings,
  consistent value spacing, sentence case for labels, caps for the header.

## Colour palette

Blueprint black `#0B0B10` + SuperteamTR red `#D6223B` on bone.
(Reverse build: white + red on washed black.)

## Logo placement

* **SuperteamTR monogram** 50 mm + wordmark, bottom-left brand block.
* **Solana logotype** 56 × 8.3 mm under the headline (logomark appears inside
  the plan's red core dot as a proportional reference, not as a redrawn mark).

## Print method recommendation

* **Screen print, 1–2 inks** (black + red on bone) — this is the concept's
  superpower: almost no ink, high thread visibility, cheapest possible run.
* Also excellent as **DTG** single-pass, and as **embroidery-friendly chest
  placement** if reduced to the plan + title block.
* Print size 280 × 355 mm on the back; a 60 × 60 mm plan-only version works as a
  pocket-area mark.

## Why it fits SuperteamTR

Turkish engineering culture and Solana builder culture share one trait: they
respect the drawing. The sheet is deliberately *documentation*, not decoration —
and the validator mesh makes it explicitly crypto-native without a single coin
symbol.

## Strengths / risks

**Strengths** — cheapest to print (1–2 inks); the most "wearable daily" of the
three directions; typography hierarchy is strong from 2 m; scales beautifully to
the back of the shirt and to A3 posters for events from the same file.

**Risks & mitigation**
* *Text-heavy* → the longest label is 28 characters at 3.2 mm cap height; the
  illustration carries the visual weight, text is a secondary layer.
* *Sheet-on-shirt costume* → the sheet is not a full rectangle of ink; the brand
  block and headline break the frame's symmetry, and the garment shows through
  between drawing elements.
* *Thin lines on bone* → hairlines are 0.45–0.7 mm and the outer tier walls are
  0.8 mm; the DTG build keeps them above 0.4 mm after RIP spread.
